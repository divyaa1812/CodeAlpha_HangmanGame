# 🎮 Hangman Game Using Python

## 📌 Project Overview

Hangman is a console-based word-guessing game developed using Python. Players guess a randomly selected hidden word one letter at a time before running out of attempts.

This project was developed as part of the CodeAlpha Python Programming Internship – Task 1.

## ✨ Features

- Random word selection
- Three difficulty levels: Easy, Medium, and Hard
- ASCII art Hangman stages
- Letter-by-letter guessing
- Six incorrect guesses allowed
- Input validation
- Repeated-guess detection
- Score tracking
- Play-again option
- Displays guessed letters and remaining attempts

## 🛠️ Technologies Used

- Python 3
- Visual Studio Code
- Python Random module

## 🧠 Python Concepts Used

- Functions
- Lists and dictionaries

- Loops and conditional statements
- Input validation
- Random selection
- Score management

## ⚙️ How to Run

1. Install Python 3.
2. Open this project folder in VS Code.
3. Open the terminal.
4. Run the command:

```bash
python hangman.py
```

On Windows, you can also use:

```bash
py hangman.py
```

No additional libraries are required.

## 🎮 How to Play

1. Run the program.
2. Choose Easy, Medium, or Hard.
3. Enter one alphabet letter at a time.
4. Correct guesses reveal letters in the hidden word.
5. Incorrect guesses advance the Hangman drawing.
6. Guess the word before using all six incorrect attempts.
7. Play again to increase your total score.

## 🏆 Scoring System

- Easy: 10 points for a win
- Medium: 20 points for a win
- Hard: 30 points for a win
